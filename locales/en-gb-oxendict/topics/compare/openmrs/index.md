OpenMRS is also open source. It describes itself as [a medical record system built by a global community](https://openmrs.org/), and reports use in more than 70 countries, with 15 million patient records. Its code is under the [Mozilla Public License 2.0](https://github.com/openmrs/openmrs-core/blob/master/LICENSE).

The two projects address different problems. OpenMRS is a clinical record that you can adapt. This project is NHS-style administration, without a clinical record.

## Comparison

| | OpenMRS | This project |
|---|---|---|
| **What it is** | An open-source medical record | Open-source patient administration |
| **Clinical record** | Yes | No, by design |
| **In use with real patients** | Yes, by its own figures | Not yet |
| **Community** | Global and long established | Small and new |
| **Designed around** | Adapting to local clinical needs | NHS Wales administration and reminders |
| **Licence** | Mozilla Public License 2.0 | MIT, Apache-2.0, BSD-3-Clause, GPL-2.0 or GPL-3.0 |

## Suitability

### When OpenMRS is suitable

You need an open-source clinical record, and a large community to learn from.

### When this project may be suitable

Your problem is appointments, reminders and waiting lists in an NHS setting.
