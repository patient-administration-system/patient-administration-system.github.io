System C, CareFlow को [एक पूर्ण नैदानिक और प्रशासनिक प्रणाली](https://www.systemc.com/the-launch-ics-ready-epr-solution/) बताता है। इसके दायरे में रोगी प्रशासन, आपातकालीन देखभाल, मातृत्व, ऑपरेशन थिएटर, दवा प्रबंधन और दूरस्थ निगरानी शामिल हैं। यह System C की Medway प्रणाली के बाद आई है, जिसे NHS के लिए बनाया गया था।

## तुलना

| | System C CareFlow | यह परियोजना |
|---|---|---|
| **यह क्या है** | नैदानिक और प्रशासनिक प्रणाली | केवल रोगी प्रशासन |
| **नैदानिक रिकॉर्ड** | हाँ | नहीं, डिज़ाइन के अनुसार |
| **वास्तविक रोगियों के साथ उपयोग में** | हाँ, NHS में | अभी नहीं |
| **सोर्स कोड** | जहाँ तक हमें पता चला, सार्वजनिक नहीं | सार्वजनिक, ओपन-सोर्स लाइसेंस |
| **आपूर्तिकर्ता सहायता** | हाँ | अभी नहीं |

## उपयुक्तता

### System C CareFlow कब उपयुक्त है

आप नैदानिक देखभाल और प्रशासन के लिए एक समर्थित NHS प्रणाली चाहते हैं।

### यह परियोजना कब उपयुक्त हो सकती है

आप रिमाइंडर और निष्पक्षता मापों के पीछे के नियम पढ़ना, या उन्हें आकार देने में मदद करना चाहते हैं।
