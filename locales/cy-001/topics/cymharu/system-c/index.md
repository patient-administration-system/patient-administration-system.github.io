Mae System C yn disgrifio CareFlow fel [system glinigol a gweinyddol lawn](https://www.systemc.com/the-launch-ics-ready-epr-solution/). Mae ei gwmpas yn cynnwys gweinyddu cleifion, gofal brys, mamolaeth, theatrau, rheoli meddyginiaethau a monitro o bell. Mae'n dilyn system Medway System C, a gynlluniwyd ar gyfer y GIG.

## Cymhariaeth

| | System C CareFlow | Y prosiect hwn |
|---|---|---|
| **Beth ydyw** | System glinigol a gweinyddol | Gweinyddu cleifion yn unig |
| **Cofnod clinigol** | Ydy | Nac ydy, yn fwriadol |
| **Yn cael ei ddefnyddio gyda chleifion go iawn** | Ydy, yn y GIG | Ddim eto |
| **Cod ffynhonnell** | Ddim yn gyhoeddus, hyd y gwyddom | Cyhoeddus, trwyddedau cod agored |
| **Cymorth cyflenwr** | Oes | Dim eto |

## Addasrwydd

### Pryd mae System C CareFlow yn addas

Rydych chi eisiau un system GIG â chymorth ar gyfer gofal clinigol a gweinyddiaeth.

### Pryd y gallai'r prosiect hwn fod yn addas

Rydych chi eisiau darllen y rheolau y tu ôl i nodiadau atgoffa a mesurau tegwch, neu helpu i'w llunio.
