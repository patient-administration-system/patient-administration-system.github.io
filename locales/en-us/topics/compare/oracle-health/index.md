Oracle Health offers [an electronic health record](https://www.oracle.com/health/clinical-suite/) and related clinical, financial and patient tools. Oracle bought Cerner, whose system is used in NHS trusts. In 2023 one London trust named Oracle Cerner as its preferred supplier in [a 10-year deal worth £44m](https://www.hsj.co.uk/technology-and-innovation/every-acute-in-ics-to-use-the-same-epr-after-44m-deal/7035475.article).

## Comparison

| | Oracle Health | This project |
|---|---|---|
| **What it is** | A whole-organization electronic health record | Patient administration only |
| **Clinical record** | Yes | No, by design |
| **In use with real patients** | Yes, including in NHS trusts | Not yet |
| **Source code** | Not public | Public, open-source licenses |
| **Supplier support** | Yes | None yet |

## Suitability

### When Oracle Health is suitable

You need a supported, organization-wide health record.

### When this project may be suitable

You want open code and a narrow focus on appointments, reminders and fair access.
