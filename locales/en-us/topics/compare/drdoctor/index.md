DrDoctor is the closest comparator for this project's reminders and replies. It [puts voice, SMS, letters and two-way messaging in one place](https://www.drdoctor.co.uk/), and it also offers waiting list validation. NHS trusts use it today: [Salisbury](https://www.salisbury.nhs.uk/patients-visitors/outpatients/quick-questions-and-patient-validation/) asks patients by secure message whether they still need an appointment, and [Calderdale and Huddersfield](https://cht.nhs.uk/patients-visitors/patient-portal/drdoctor) uses it for interactive messaging.

DrDoctor works alongside a hospital's electronic record, while this project is a patient administration system with messaging built in.

## Comparison

| | DrDoctor | This project |
|---|---|---|
| **What it is** | A patient communication platform | A patient administration system |
| **Reminders and two-way messages** | Yes | Yes |
| **Waiting list validation** | Yes | Yes |
| **Holds the bookings itself** | Works with the hospital's record | Yes |
| **In use with real patients** | Yes, in NHS trusts | Not yet |
| **Source code** | Not public, as far as we can find | Public, open-source licenses |

## Suitability

### When DrDoctor is suitable

You want patient messaging working now, alongside the systems you already have.

### When this project may be suitable

You want reminders, replies and fairness rules that you can read, test and change.
