تصف System C نظام CareFlow بأنه [نظام سريري وإداري كامل](https://www.systemc.com/the-launch-ics-ready-epr-solution/). ويشمل نطاقه إدارة المرضى ورعاية الطوارئ والأمومة وغرف العمليات وإدارة الأدوية والمراقبة عن بعد. وهو يأتي بعد نظام Medway من System C، الذي صُمم من أجل NHS.

## المقارنة

| | System C CareFlow | هذا المشروع |
|---|---|---|
| **ما هو** | نظام سريري وإداري | إدارة المرضى فقط |
| **السجل السريري** | نعم | لا، بحكم التصميم |
| **مستخدم مع مرضى حقيقيين** | نعم، في NHS | ليس بعد |
| **الشيفرة المصدرية** | غير عامة، بحسب ما توصلنا إليه | عامة، بتراخيص مفتوحة المصدر |
| **دعم المورّد** | نعم | لا يوجد بعد |

## الملاءمة

### متى يناسب System C CareFlow

تريد نظامًا واحدًا مدعومًا في NHS للرعاية السريرية والإدارة.

### متى قد يناسب هذا المشروع

تريد قراءة القواعد التي تحكم التذكيرات ومقاييس الإنصاف، أو المساعدة في صياغتها.
