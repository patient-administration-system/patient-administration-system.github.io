Nervecentre 向 NHS 信托提供电子病历。Mid Yorkshire 为其云端系统签署了[十年合同](https://www.midyorks.nhs.uk/news/mid-yorkshire-signs-epr-contract-with-nervecentre-4506)。在 Harrogate and District，它[取代了许多旧系统和纸质流程](https://www.hdft.nhs.uk/news/harrogate-and-district-nhs-foundation-trust-successfully-launches-phase-two-of-its-electronic-patient-record-system/)。德比郡的两家信托在[七家供应商中](https://uhdb.nhs.uk/latest-news/new-electronic-patient-record-system-one-step-closer-as-preferred-supplier-identified-16684)给了它最高分。

## 比较

| | Nervecentre | 本项目 |
|---|---|---|
| **是什么** | 云端电子病历 | 仅限患者行政管理 |
| **临床记录** | 是 | 否，这是设计决定 |
| **用于真实患者** | 是，在 NHS 信托中 | 尚未 |
| **源代码** | 未公开（据我们所知） | 公开，采用开源许可证 |
| **供应商支持** | 有 | 暂无 |

## 适用情况

### Nervecentre 的适用情况

你需要为医院信托选择一套有技术支持的电子病历。

### 本项目的适用情况

你关注的是可以检查和修改的提醒、回复和公平性衡量。它不是临床系统。
