System C 将 CareFlow 描述为[完整的临床和行政系统](https://www.systemc.com/the-launch-ics-ready-epr-solution/)。其范围包括患者管理、急诊、产科、手术室、药物管理和远程监测。它承接了 System C 为 NHS 设计的 Medway 系统。

## 比较

| | System C CareFlow | 本项目 |
|---|---|---|
| **是什么** | 临床和行政系统 | 仅限患者行政管理 |
| **临床记录** | 是 | 否，这是设计决定 |
| **用于真实患者** | 是，在 NHS 中 | 尚未 |
| **源代码** | 未公开（据我们所知） | 公开，采用开源许可证 |
| **供应商支持** | 有 | 暂无 |

## 适用情况

### System C CareFlow 的适用情况

你想要一套有技术支持、同时覆盖临床和行政的 NHS 系统。

### 本项目的适用情况

你想阅读提醒和公平性衡量背后的规则，或帮助塑造这些规则。
