Oracle Health 提供[电子健康记录](https://www.oracle.com/health/clinical-suite/)以及相关的临床、财务和患者工具。Oracle 收购了 Cerner，后者的系统在 NHS 信托中使用。2023 年，伦敦一家信托选定 Oracle Cerner 为首选供应商，签订了[为期 10 年、价值 4400 万英镑的协议](https://www.hsj.co.uk/technology-and-innovation/every-acute-in-ics-to-use-the-same-epr-after-44m-deal/7035475.article)。

## 比较

| | Oracle Health | 本项目 |
|---|---|---|
| **是什么** | 覆盖整个机构的电子健康记录 | 仅限患者行政管理 |
| **临床记录** | 是 | 否，这是设计决定 |
| **用于真实患者** | 是，包括 NHS 信托 | 尚未 |
| **源代码** | 未公开 | 公开，采用开源许可证 |
| **供应商支持** | 有 | 暂无 |

## 适用情况

### Oracle Health 的适用情况

你需要一套有技术支持、覆盖整个机构的健康记录。

### 本项目的适用情况

你想要开放的代码，并专注于预约、提醒和公平就医。
