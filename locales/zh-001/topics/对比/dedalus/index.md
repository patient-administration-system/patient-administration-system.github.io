这是最接近本项目的商业比较对象，因为 Dedalus 单独销售患者管理系统。它将 ORBIS PAS 描述为面向英国和爱尔兰的[新一代患者管理系统](https://www.dedalus.com/uki/wp-content/uploads/sites/7/2026/07/ORBIS-PAS-Flyer-for-web.pdf)，也是迈向完整电子记录的第一步。Dedalus [已在这两个国家推出该产品](https://www.dedalus.com/uki/media/news/dedalus-launches-orbis-pas-across-uk-and-ireland/)。

## 比较

| | Dedalus ORBIS | 本项目 |
|---|---|---|
| **是什么** | 患者行政管理，并可升级到完整记录 | 仅限患者行政管理 |
| **临床记录** | 可通过 ORBIS 获得 | 否，这是设计决定 |
| **基础** | Dedalus 自述的 NHS 和爱尔兰卫生服务经验 | 全新代码，尚未在实际使用中验证 |
| **源代码** | 未公开（据我们所知） | 公开，采用开源许可证 |
| **供应商支持** | 有 | 暂无 |

## 适用情况

### Dedalus ORBIS 的适用情况

你需要一套有技术支持的患者管理系统，有供应商，也有通往完整记录的路径。

### 本项目的适用情况

你想检查和修改提醒、回复和公平性衡量的运作方式。
