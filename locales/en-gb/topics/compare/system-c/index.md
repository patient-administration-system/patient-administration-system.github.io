System C describes CareFlow as [a full clinical and administration system](https://www.systemc.com/the-launch-ics-ready-epr-solution/). Its scope includes patient administration, emergency care, maternity, theatres, medicines management and remote monitoring. It follows System C's Medway system, which was designed for the NHS.

## Comparison

| | System C CareFlow | This project |
|---|---|---|
| **What it is** | A clinical and administration system | Patient administration only |
| **Clinical record** | Yes | No, by design |
| **In use with real patients** | Yes, in the NHS | Not yet |
| **Source code** | Not public, as far as we can find | Public, open-source licences |
| **Supplier support** | Yes | None yet |

## Suitability

### When System C CareFlow is suitable

You want one supported NHS system for clinical care and administration.

### When this project may be suitable

You want to read the rules behind reminders and fairness measures, or help to shape them.
