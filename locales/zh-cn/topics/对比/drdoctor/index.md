DrDoctor 是最接近本项目提醒和回复功能的产品。它[将语音、短信、信件和双向消息集中在一处](https://www.drdoctor.co.uk/)，还提供候诊名单核实。NHS 信托如今都在使用它：[Salisbury](https://www.salisbury.nhs.uk/patients-visitors/outpatients/quick-questions-and-patient-validation/) 通过安全消息询问患者是否仍需要预约，[Calderdale and Huddersfield](https://cht.nhs.uk/patients-visitors/patient-portal/drdoctor) 用它提供互动消息服务。

DrDoctor 与医院的电子记录配合使用，而本项目是内置消息功能的患者管理系统。

## 比较

| | DrDoctor | 本项目 |
|---|---|---|
| **是什么** | 患者沟通平台 | 患者管理系统 |
| **提醒和双向消息** | 有 | 有 |
| **候诊名单核实** | 有 | 有 |
| **自身保存预约** | 与医院记录配合 | 是 |
| **用于真实患者** | 是，在 NHS 信托中 | 尚未 |
| **源代码** | 未公开（据我们所知） | 公开，采用开源许可证 |

## 适用情况

### DrDoctor 的适用情况

你现在就想在现有系统之外使用患者消息服务。

### 本项目的适用情况

你想要可以阅读、测试和修改的提醒、回复和公平性规则。
