OpenMRS 同样是开源项目。它自称是[由全球社区构建的医疗记录系统](https://openmrs.org/)，并报告在 70 多个国家使用，有 1500 万份患者记录。其代码采用 [Mozilla Public License 2.0](https://github.com/openmrs/openmrs-core/blob/master/LICENSE)。

这两个项目针对不同的问题。OpenMRS 是可以调整的临床记录，而本项目是医院行政管理，不含临床记录。

## 比较

| | OpenMRS | 本项目 |
|---|---|---|
| **是什么** | 开源医疗记录 | 开源患者行政管理 |
| **临床记录** | 是 | 否，这是设计决定 |
| **用于真实患者** | 是，根据其自身数据 | 尚未 |
| **社区** | 全球性且历史悠久 | 规模小且新 |
| **设计重点** | 适应当地临床需求 | 医院的行政管理和提醒 |
| **许可证** | Mozilla Public License 2.0 | MIT、Apache-2.0、BSD-3-Clause、GPL-2.0 或 GPL-3.0 |

## 适用情况

### OpenMRS 的适用情况

你需要开源临床记录，以及可以借鉴的大型社区。

### 本项目的适用情况

你要解决的是医院或诊所中的预约、提醒和候诊名单问题。
